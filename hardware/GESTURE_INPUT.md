# NUCODE → UI 모션 입력 규격

보드는 모션을 감지한 뒤 HID 키 누름/해제 한 쌍을 전송한다. UI는 keydown에서만 처리하며 자동 반복은 무시한다. 실제 모션 감지 펌웨어는 아직 구현되지 않았다.

| 동작 | 모션 | 키 | UI 처리 |
| --- | --- | --- | --- |
| 녹음 시작·종료 | Roll: 손목→손가락 방향 축으로 문고리를 돌리듯 비틀었다 복귀 | Space | 한 번 시작, 다음 한 번 종료 |
| 확정 | Pitch: 손끝을 아래·위로 움직여 끄덕임 | F13 | 미확정 초안만 로컬 확정 |
| 재녹음 | Yaw: 손끝을 좌·우로 부채질 | F14 | 초안을 화면에서 내리고 즉시 녹음 시작; Roll로 종료 |

Pitch 축은 손등 평면 내 좌우 방향, Yaw 축은 손등에 수직인 방향이다. 센서 좌표축은 보드 장착 방향에 맞춰 실제로 보정해야 한다. 돌아오는 동작을 두 번째 명령으로 보내지 않도록 왕복 모션당 한 번만 전송한다. 임계값·재무장·쿨다운은 실제 보드에서 보정한다.

녹음·처리 중 확정/재녹음은 무시한다. 입력창에 포커스가 있으면 키를 무시한다. 브라우저 페이지가 활성화되어 있어야 한다. 기존 nucode_ptt.ino는 ESP32 물리 버튼 예시이며 이 모션 펌웨어가 아니다.
